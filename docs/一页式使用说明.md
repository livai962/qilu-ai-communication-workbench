# 一页式使用说明 · 齐鲁智传 · 山东本土文化 AI 传播智能工作台

> 目标：评审无需指导即可独立跑通。预计操作时间 3–5 分钟。

## 一、启动方式

```bash
cd qilu-ai-communication-workbench
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开终端提示地址（默认 `http://localhost:8501`）。未配置大模型 Key 也可直接使用，系统自动运行本地离线引擎。

## 二、操作四步走

### 第 1 步：填写（左侧面板）
1. 选择**传播场景**：齐鲁非遗 / 老字号焕新、县域文旅打卡、助农农产品；
2. 填写**项目 / 产品名称**、**核心卖点与资料**、**目标受众**、**受众痛点**；
3. 勾选**分发平台**（小红书 / 抖音 / 公众号）；
4. 拖动**风格滑块**（政务专业 ↔ 年轻网感），选择篇幅，可补充附加约束。

> 想快速体验：点击左侧「典型场景 / 复杂输入 / 边界异常」按钮一键加载内置案例。

### 第 2 步：生成
点击左下 **🚀 一键生成内容矩阵**。右侧工作台输出：主推文案、分平台适配文案、话题标签、短视频分镜、AI 配图提示词。

### 第 3 步：校验与人工校准
- **Tab「文案预览与编辑」**：直接修改标题、正文与各平台文案，点击「💾 保存人工修改并留痕」；
- **Tab「分镜脚本与配图」**：在表格中编辑分镜单元格，修改配图提示词后保存；
- **Tab「合规校验与协作留痕」**：查看合规结论、命中明细与法规依据、受众痛点击中率；可点击「✨ 一键合规润色」，并在 Diff 面板查看 AI 初稿与修订版差异；修改日志带时间戳与前后对比。

### 第 4 步：导出
底部操作栏：
- **⬇️ 导出 Markdown** / **⬇️ 导出 Word(.docx)**；
- 展开「纯文本预览」可直接复制；
- 「💾 保存本次会话留痕」将输入、AI 初稿、修改轨迹与溯源 ID 写入本地记录。

## 三、常见情况

| 情况 | 处理 |
| --- | --- |
| 提示缺少必填项 | 按左侧提示补全项目名称、卖点、受众与平台后再生成 |
| 合规明细出现红色高风险 | 查看命中词与依据，使用一键润色或人工改写后重新校验 |
| 在线模型不可用 | 系统自动降级本地引擎，界面提示降级原因，流程不受影响 |
| 想还原初稿 | 在文案页点击「↩️ 还原为 AI 初稿」 |

## 四、验收自检清单

- [ ] 不填内容直接点生成：出现友好补全提示，不崩溃；
- [ ] 加载典型案例并生成：文案、标签、分镜、配图提示词完整；
- [ ] 修改一处文案并保存：协作日志出现一条带时间戳的记录；
- [ ] 导出 Markdown 与 Word：文件含溯源 ID 与提示词版本；
- [ ] 合规页可查看命中词、类别、依据与修改建议。

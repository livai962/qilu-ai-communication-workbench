## 案例二 · 复杂输入：沾化冬枣多平台种草 + 直播预热

### 1. 输入

| 字段 | 内容 |
| --- | --- |
| 传播场景 | 助农农产品 |

| 核心卖点与资料 | 山东滨州沾化核心产区；沙地种植，日照充足；脆甜多汁、皮薄核小；现摘现发，冷链包邮；9 月下旬至 10 月中旬上市；5 斤装礼盒，支持企业团购 |

| 附加约束 | 兼顾种草、直播预热与品牌图文；不得承诺疗效；团购信息以店铺实际为准 |

### 2. 运行过程

1. 加载「复杂输入」案例，参数含多项产地、规格、政策与多平台需求；
2. 生成工作流先将长资料提炼为结构化卖点，再并行产出三平台内容；

- **主标题**：沾化冬枣（产地直供）｜特色鲜明、内容扎实，采购消费者值得一看的齐鲁选择
- **分平台适配**：
  - 小红书：体验安利式长图文，含产地、口感与选购小贴士；
  - 抖音：3 秒钩子 → 痛点 → 卖点 → 互动引导口播脚本；
  - 公众号：概览 → 特色亮点 → 适配场景 → 温馨提示的结构化图文；
- **分镜脚本**：5 镜，覆盖主体亮相、痛点、卖点特写、品尝体验与收尾引导；

| 目标受众 | 亲子家庭 |
| 受众痛点 | 担心体验项目走马观花、孩子学不到东西 |
| 分发平台 | 抖音 |
| 附加约束 | 初稿需检验合规：不得出现“全国第一”“最佳”“包治”等表述 |

**3b. 空白 / 缺项输入**：清空项目名称、卖点、受众等必填项后直接点击生成。

### 2. 运行过程

1. 加载「边界 / 异常输入」案例；
2. 合规引擎对**输入侧**诉求文本扫描，命中约束中列举的“全国第一、最佳、包治”等高风险表述，分级高亮并附类别、法规依据与修改建议；
3. 内容侧生成稿经扫描未引入违规词；“国家级非遗”作为官方称谓被语境排除，不误判为极限用语；
4. 切换到空白输入：校验层拦截，前端给出“缺少必填项 / 卖点信息过少 / 请选择平台”的友好提示，不产生空输出、不崩溃；
5. 必要时使用「一键合规润色」，系统将风险词替换为稳妥表述并记录替换轨迹，最终由人工确认。

### 3. 最终输出（AI 初稿摘要）

- **主标题**：潍坊风筝｜出片、好逛、有料，亲子家庭值得一看的齐鲁选择
- **抖音口播**：钩子 → 痛点 → 卖点（手绘工艺、定制图案、亲子研学 DIY）→ 互动引导；
- **分镜与配图**：5 镜脚本 + 3 条配图提示词；
- **合规面板**：输入侧风险提示列出命中词与依据；内容侧结论为低风险。

# 初赛简要说明 · 齐鲁智传 · 山东本土文化 AI 传播智能工作台

> 篇幅控制：本说明不超过 2 页。配套可运行原型见工程主程序 `app.py`。

## 1. 目标用户

| 用户类型 | 典型角色 | 现实处境 |
| --- | --- | --- |
| 县域文旅宣传人员 | 县 / 区文旅局宣传干事、景区运营 | 人手少、选题重复，内容难融合好客山东与齐鲁文化元素 |
| 非遗 / 老字号品牌方 | 传承人、品牌运营、小店主理人 | 不懂年轻化表达，缺网感文案与短视频脚本，多平台适配成本高 |
| 助农农产品运营者 | 合作社、产地直供卖家、带货助手 | 卖点零散、不会结构化表达，且容易触碰功效宣称等合规红线 |

## 2. 嵌入业务环节

工具嵌入营销传播内容生产的**前期策划 → 初稿生产 → 审核校准 → 定稿导出**四个环节：

1. **策划录入**：以结构化表单锁定场景、项目、卖点、受众、痛点、平台与风格；
2. **初稿生产**：一次性产出多平台内容矩阵（文案、标签、分镜、配图提示词）；
3. **审核校准**：系统做合规扫描与受众命中分析，人工在线二次修改；
4. **定稿导出**：导出 Markdown / Word，留存完整人机协作日志与溯源 ID。

使用频率：单条内容生产链路内多次使用；可复用于每一篇推文、每一条短视频脚本的生产。

## 3. 价值预期（可量化）

| 对比项 | 传统人工方式 | 本工具辅助方式 | 改善预期 |
| --- | --- | --- | --- |
| 单条长图文初稿耗时 | 约 120 分钟（选题 + 撰稿 + 多平台改写） | 约 15 分钟（生成 + 人工微调） | 效率提升约 87% |
| 多平台适配 | 逐平台重写，口径易不一致 | 一次录入、分平台结构化适配 | 改写成本显著下降 |
| 合规风险 | 依赖个人经验，易遗漏极限词 / 功效宣称 | 词库分级扫描 + 法规依据 + 润色建议 | 风险前置暴露、可追溯 |
| 协作留痕 | 沟通分散在聊天记录，难复盘 | 修改轨迹、提示词版本、溯源 ID 本地落盘 | 过程可复核、可举证 |

**适用边界**：工具产出为“待人工校准的初稿”，不替代事实核查、资质审核与最终发布决策；不生成虚假数据、不承诺疗效或收益；涉及检测报告、资质、价格时效的内容须以官方依据为准。

## 4. 核心功能

1. **结构化场景录入**：三类本土场景下拉锁定，要素表单替代通用聊天框，强化垂直定制属性。
2. **多平台内容矩阵**：主推文案、小红书 / 抖音 / 公众号适配文案、话题标签、5 镜分镜脚本、AI 配图提示词并行产出。
3. **合规分级预警**：内置广告法极限词、夸大承诺、功效宣称、违规引流、低俗词五类词库，分级标注命中位置、类别、法规依据与修改建议；支持一键合规润色。
4. **受众命中分析**：基于痛点 / 兴趣词覆盖计算痛点击中率、卖点覆盖率与情绪倾向，给出补全建议。
5. **人机协作留痕**：在线编辑、字符级 Diff 比对、时间戳修改日志、AI 初稿与修订版双版本留存、唯一溯源 ID。
6. **多格式导出**：Markdown、Word(.docx)、纯文本复制，导出件附带溯源标识与提示词版本。
7. **离线可跑通**：未配置大模型 Key 时由本地规则模板引擎兜底，保证演示与评审现场稳定可用。

## 5. 技术路径

- **前端**：Python + Streamlit，左右分栏 + Tab 工作台，评审点开即可操作。
- **业务与提示词层**：内置齐鲁文化元素库、平台爆款结构库、合规词库；系统提示词注入营销专业逻辑、本土文化属性与合规红线，模板可配置、带版本号。
- **服务层**：优先对接 OpenAI 兼容大模型接口（豆包 / 通义 / 商汤等）；异常或未配置时自动切换本地离线引擎，两种引擎输出同一数据契约。
- **存储层**：本地 JSON 持久化三类数据——原始输入、AI 全版本初稿、人工修改全轨迹。
- **安全**：API Key 仅经环境变量 / `.env` 注入，禁止硬编码；运行期会话数据不进入公开仓库。

## 6. 差异化亮点

- 不做“通用 AI 文案套壳”，深度绑定山东文旅、非遗老字号、助农三类本土场景；
- 在内容生成之外拓展**风险预警**与**受众命中评估**两类评估型能力；
- 全链路人机留痕可直接在答辩中演示 Diff 与日志；
- 双引擎 + 本地 Plan B，兼顾在线智能与离线可用性。

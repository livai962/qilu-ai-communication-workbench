# 三分钟演示视频脚本 · 齐鲁智传

> 时长控制：≤ 3 分钟。形式：屏幕录制 + 口播解说。建议提前唤醒在线服务；离线环境直接本地运行 `streamlit run app.py`。

## 一、录制前准备

1. 启动工具，确认左侧案例按钮、右侧三个 Tab、底部导出栏可见；
2. 准备三个内置案例：典型场景、复杂输入、边界异常；
3. 关闭无关弹窗，浏览器缩放至 100%，保证文字清晰；
4. 备用：本地工程包、本脚本、三分钟录屏文件，应对现场无网络。

## 二、分镜脚本

| 时间 | 画面 / 操作 | 口播要点 |
| --- | --- | --- |
| 0:00–0:20 | 展示标题 Banner、引擎与提示词版本信息 | “这是面向山东县域文旅、非遗老字号和助农农产品的 AI 传播智能工作台，AI 出初稿、人工定终稿，全过程可溯源。” |
| 0:20–0:50 | 左侧加载「典型场景」案例，逐项展示表单字段 | “工具用结构化表单锁定场景、卖点、受众、痛点、平台和风格，而不是通用聊天框；信息一次录入。” |
| 0:50–1:20 | 点击「一键生成」，展示右侧文案、标签、分镜、配图提示词 | “一次生成多平台内容矩阵：主推文案、分平台适配、话题标签、五镜分镜和 AI 配图提示词。” |
| 1:20–1:50 | 切到合规 Tab，展示风险结论、命中明细、法规依据与受众命中率 | “系统先做合规分级扫描，附命中类别、法规依据和修改建议；同时评估受众痛点击中率与卖点覆盖。” |
| 1:50–2:20 | 回到文案 Tab，修改一处措辞，保存留痕；展示 Diff 与修改日志 | “人工可在线直接编辑，保存后系统做版本比对，记录时间戳、字段和前后差异，过程完整留痕。” |
| 2:20–2:40 | 加载「边界异常」案例，展示输入侧风险提示；再演示空白输入容错提示 | “遇到违规倾向表述会分级预警；空白或缺项输入给出友好提示，工具不崩溃。” |
| 2:40–3:00 | 演示导出 Markdown / Word，展示文件尾部溯源 ID 与提示词版本；收尾 | “导出件带溯源 ID 和版本号；未配置大模型时本地引擎兜底，保证现场可独立跑通。” |

## 三、答辩可补充的亮点话术

- “区别于通用文案套壳，我们深度绑定山东本土三类场景，并把文化元素与平台结构内置进工作流。”
- “除了生成，工具还具备风险预警和受众命中评估两类评估型能力。”
- “人机边界清晰：AI 负责初稿与提示，人工负责事实核查、合规确认和发布决策。”
- “双引擎设计：在线模型可用时调用大模型，异常或离线时自动降级本地规则引擎，演示稳定可控。”

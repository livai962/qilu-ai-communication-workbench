> 2026 山东省首届大学生 AI 大模型创新传播大赛 · 赛道三（AI 传播工具创新赛道）参赛作品
>
> 文件命名规范：`赛道三-<学校名称>-<团队名称>-齐鲁智传·山东本土文化AI传播智能工作台`

## 一、项目一句话定位

面向**县域文旅局、非遗 / 老字号品牌方、助农农产品运营者**三类人手有限的小团队，提供从「结构化要素录入 → 多平台内容矩阵生成 → 合规与受众双校验 → 人工在线校准 → 多格式导出留痕」的全链路智能化传播工具。AI 只出初稿，人工掌握最终发布决策权，全过程可编辑、可复核、可溯源。

## 二、快速开始

### 1. 环境要求
- Python 3.10+（开发验证版本 3.12）
- 无需外网、无需大模型 Key 即可完整跑通（内置本地离线兜底引擎）

### 2. 安装与运行

```bash
# 进入工程目录
cd qilu-ai-communication-workbench

# 安装依赖
pip install -r requirements.txt

# 启动
streamlit run app.py
```

或使用一键脚本：

```bash
bash run.sh
```

浏览器打开终端提示的地址（默认 `http://localhost:8501`）即可使用。

### 3. 接入在线大模型（可选）

复制 `.env.example` 为 `.env`，填入 OpenAI 兼容接口配置：

```bash
LLM_ENABLED=true
LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
LLM_MODEL=doubao-pro-32k
LLM_API_KEY=你的密钥
```

- 未配置 Key 或调用异常时，工具**自动降级**为本地离线引擎，界面与输出契约保持一致；
- 密钥仅通过环境变量 / 本地 `.env` 注入，不写入前端代码与公开仓库（`.env` 已在 `.gitignore` 排除）。

## 七、设计与合规约定

- **人机边界**：AI 负责提炼卖点、生成初稿、提示风险；人工负责事实核对、合规确认与最终发布决策，工具不输出“可直接定稿”的承诺。
- **可溯源**：每次生成分配唯一溯源 ID（`QL-日期-随机码`），导出文件附带 AI 生成 + 人工校验标识与提示词版本号。
- **容错运行**：空白 / 缺项输入给出友好提示；在线模型不可用时自动降级本地引擎；输出可编辑、可导出、可回溯。
- **数据说明**：内置案例为演示用模拟素材；涉及数据、比例、资质的表述均提示“以官方发布 / 检测依据为准”。
